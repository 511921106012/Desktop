# Embedded Systems & C/C++ Practice Portfolio

Welcome to my central repository containing C programming practice problems, data structures, Linux internal concepts, and embedded hardware projects developed during my training at **Emertxe Information Technologies**.

## 🛠️ Tech Stack & Focus Areas

* **Programming Languages:** Embedded C, C++, Data Structures & Algorithms (DSA)
* **Operating Systems:** Linux Architecture, Shell Commands, System Calls
* **Hardware & Microcontrollers:** PIC Microcontrollers, CAN Protocol Interfacing, Digital Displays (SSDs)
